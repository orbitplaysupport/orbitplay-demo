OrbitPlay — demonstration playlist

Test material for reviewing the application. Not bundled with the app.

OrbitPlay is a media player. It does not provide, host, sell or promote any media content. The application ships with no playlists: every source is added by the user.

This playlist exists so the application can be evaluated without a third-party subscription. Every stream in it is published freely and publicly by its own rights holder.

How to load it

Open OrbitPlay, tap +, choose Import from URL and paste:

https://orbitplaysupport.github.io/orbitplay-demo/demo-playlist.m3u

That single link is all that is needed — the programme guide is referenced from inside the playlist and loads automatically. No separate guide URL has to be entered.
