# OrbitPlay — demonstration playlist

Test material for reviewing the OrbitPlay media player. **Not bundled with the application.**

OrbitPlay does not provide, host, sell or promote any media content. The app ships with no
playlists; every source is added by the user. These files exist so the application can be
evaluated without a third-party subscription.

Every stream referenced here is published freely and publicly by its own rights holder:
official reference streams, public broadcast streams, and open films under Creative Commons.

## One link is enough

```
https://orbitplaysupport.github.io/orbitplay-demo/demo-playlist.m3u
```

The programme guide is referenced from inside the playlist, so it loads on its own — no separate
guide URL needs to be entered.

| File | Purpose |
|---|---|
| `demo-playlist.m3u` | Playlist, 7 entries in three groups |
| `demo-epg.xml.gz` | Programme guide, XMLTV, gzip |
| `demo-epg.xml` | Same guide, uncompressed |

The guide covers 45 days from 30 August 2026. Listings are synthetic and labelled as such.
